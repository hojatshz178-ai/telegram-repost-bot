# ربات خبری نظامی — نسخه‌ی فقط-تلگرام

این ربات فقط از کانال‌های تلگرام خبر می‌گیرد (پشتیبانی از سایت/RSS به دلیل مسدود شدن توسط سیستم‌های ضدربات آن سایت‌ها کاملاً حذف شد). با Gemini بازنویسی می‌کند (سبک گزارش نظامی)، پست‌های نامرتبط را فیلتر می‌کند، پست‌های پشت‌سرهمِ مرتبط به یک رویداد را ادغام می‌کند، اولویت‌بندی می‌کند، عکس/فیلم (حتی آلبوم) را حفظ می‌کند، و در صورت خطا پست را گم نمی‌کند.

## متغیرهای محیطی (Railway → Variables)

### الزامی
| نام متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن رباتی که از BotFather گرفتی |
| `TARGET_CHAT_ID` | آیدی کانال خودت، مثل `@khaatshekaan` |
| `GEMINI_API_KEYS` | همه‌ی کلیدهای Gemini، با کاما جدا (الان ۲۹ تا) |
| `SOURCE_CHANNELS` | یوزرنیم کانال‌های تلگرام با کاما، بدون @ |

### اختیاری
| نام متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `GEMINI_MODELS` | `gemini-2.5-flash-lite,gemini-2.0-flash-lite` | لیست مدل‌ها؛ اگر مدل اول مدام سقف/۵۰۳ بدهد، خودکار مدل بعدی امتحان می‌شود |
| `PEXELS_API_KEY` | خالی | برای عکس استوک وقتی پست تلگرامی خودش عکس/فیلم ندارد |
| `POLL_INTERVAL_SECONDS` | 300 | هر چند ثانیه کانال‌ها چک شوند |
| `SITE_POST_SPACING_MINUTES` / `SITE_POST_MIN_SPACING_MINUTES` | 60 / 30 | سقف/کف فاصله‌ی پخش صف باقی‌مانده‌ی شب |
| `BURST_MIN_POSTS` | 4 | چند پست پشت‌سرهم باعث ادغام/جمع‌بندی شود |
| `QUEUE_PURGE_KEEP_PRIORITY_MAX` | 2 | در نیمه‌شب فقط اولویت ۱ و ۲ در صف باقی می‌مانند |
| `MAX_RETRY_ATTEMPTS` | 3 | سقف تلاش مجدد پست خراب |
| `DEDUP_WINDOW_MINUTES` / `DEDUP_SIMILARITY_THRESHOLD` | 240 / 0.72 | تشخیص پست تکراری |
| `SOURCE_COOLDOWN_BASE_SECONDS` / `SOURCE_COOLDOWN_MAX_SECONDS` | 300 / 3600 | استراحت کانال‌های خراب |

## نکته‌ی حیاتی درباره‌ی سقف رایگان Gemini (بخوان قبل از شکایت از خطا)

سقف رایگان **روی سطح پروژه‌ی گوگل اعمال می‌شود، نه روی سطح کلید API**. اگر چند تا از کلیدهایت را از یک پروژه‌ی مشترک ساخته باشی (مثلاً چون موقع ساخت کلید جدید بدون دقت همون پروژه‌ی قبلی رو انتخاب کردی)، چرخش بین آن‌ها عملاً سهمیه را زیاد نمی‌کند. برای چک کردن: در `aistudio.google.com/apikey` روی هر کلید بزن و زیر «Project name» ببین چند تا کلید زیر یک پروژه‌ی مشترک هستند.

از ۷ دسامبر ۲۰۲۵، گوگل سهمیه‌ی رایگان را ۵۰ تا ۸۰ درصد کاهش داد؛ الان `gemini-2.5-flash` معمولی حدود ۱۰ درخواست در دقیقه و چند صد درخواست در روز سقف دارد. به همین دلیل پیش‌فرض این ربات را روی `gemini-2.5-flash-lite` (و در صورت مشکل، `gemini-2.0-flash-lite`) گذاشتیم که معمولاً سقف بالاتر و پایداری بهتری دارند.

## چرخش دوگانه: هم بین کلیدها، هم بین مدل‌ها

هر تلاش، یک ترکیب (کلید، مدل) را امتحان می‌کند. اگر با یک ترکیب به خطای ۴۲۹/۵۰۰/۵۰۳/۴۰۱/۴۰۳ برخورد کرد، بلافاصله ترکیب بعدی (کلید دیگر یا مدل دیگر) را امتحان می‌کند؛ اگر همه‌ی ترکیب‌ها در یک دور ناموفق بودند، با تأخیر فزاینده‌ی واقعی (۱۵ → ۳۰ → ۶۰ → ۱۲۰ ثانیه) دوباره تلاش می‌کند.

## نکته‌ی حیاتی: ساختن Volume روی Railway

بدون این مرحله، فایل حافظه‌ی ربات (صف، دی‌دوپ، فلگ پیام‌های روزانه) با هر دیپلوی یا ری‌استارت پاک می‌شود:
1. در سرویس `worker` → **New → Volume**
2. Mount Path: دقیقاً `/data`
3. Deploy بزن

## قابلیت‌ها (خلاصه)

- فقط کانال‌های تلگرام؛ بدون هیچ اتصال به سایت/RSS.
- ادغام پست‌های انبوهِ مرتبط به یک رویداد به‌جای پیاپی‌پست‌زدن.
- اولویت ۴سطحی (رویداد نظامی فعال > خاورمیانه/ایران > قدرت‌های بزرگ > سایر جهان) با پاک‌سازی نیمه‌شبِ سطح‌های کم‌اهمیت.
- سکوت شبانه‌ی ۰۰:۰۰ تا ۰۸:۰۰ با استثنای خبر فوری، و صف پخش پویا (۳۰ تا ۶۰ دقیقه) برای باقی‌مانده‌ی شب.
- پیام صبح‌بخیر (۸ صبح) و شب‌بخیر (۰۰:۰۰) خودکار.
- عکس/آلبوم/فیلم پست تلگرام مستقیم دانلود و آپلود می‌شود (نه فقط لینک).
- گم نشدن پست هنگام خطا (retry تا ۳ بار، بعد کنارگذاری نهایی).
- مدیریت flood-control تلگرام و استراحت خودکار کانال‌های خراب.
- HTML امن (کل متن escape می‌شود) و تقسیم هوشمند کپشن طولانی‌تر از ۱۰۲۴ کاراکتر.

## محدودیت‌های شناخته‌شده

- اسکرپ HTML صفحه‌ی عمومی تلگرام است، نه API رسمی؛ فقط کانال‌های پابلیک کار می‌کنند.
- دی‌دوپ بر پایه‌ی شباهت متنی است، نه فهم معنایی واقعی رویداد.
- محتوای ویدئو تحلیل نمی‌شود، فقط کپشن متنی آن.
- بدون لایه‌ی تأیید انسانی برای خبر فوری (طبق طراحی خواسته‌شده).
