# ربات خبری نظامی — نسخه نهایی

این ربات از کانال‌های تلگرام **و** فیدهای RSS سایت‌های خبری، خبر و تحلیل جمع می‌کند، با Gemini آن‌ها را کاملاً بازنویسی می‌کند (سبک گزارش نظامی)، پست‌های نامرتبط/تبلیغاتی را حذف می‌کند، از پست تکراری یک رویداد جلوگیری می‌کند، عکس/فیلم پست‌های تلگرام را حفظ می‌کند، برای پست‌های سایت در صورت نبود عکس یک عکس استوک مرتبط پیدا می‌کند، و هر روز ساعت ۷ صبح و ۲۴ شب (به وقت تهران) پیام خودکار می‌فرستد.

## متغیرهای محیطی (Railway → Variables)

| نام متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن رباتی که از BotFather گرفتی |
| `TARGET_CHAT_ID` | آیدی کانال خودت، مثل `@khaatshekaan` |
| `GEMINI_API_KEY` | کلید Gemini |
| `SOURCE_CHANNELS` | یوزرنیم کانال‌های تلگرام با کاما، بدون @ (مثل `channel1,channel2`) |
| `SOURCE_WEBSITES` | آدرس فید RSS سایت‌ها با کاما (اختیاری — اگه سایتی نداری خالی بذار) |
| `POLL_INTERVAL_SECONDS` | (اختیاری) هر چند ثانیه چک کنه، پیش‌فرض ۳۰۰ |
| `DEDUP_WINDOW_MINUTES` | (اختیاری) بازه‌ی زمانی تشخیص پست تکراری، پیش‌فرض ۲۴۰ دقیقه |

## نکات مهم درباره‌ی قابلیت‌ها

- **فیلتر محتوای نامرتبط:** قبل از بازنویسی، از خود Gemini می‌پرسیم آیا این محتوا واقعاً خبر نظامی/امنیتی است یا نه؛ اگر تبلیغاتی یا متفرقه بود، اصلاً پست نمی‌شود.
- **جلوگیری از پست تکراری:** اگه چند کانال/سایت همزمان یک رویداد رو پوشش بدن، ربات با مقایسه‌ی شباهت تیترها در یک بازه‌ی زمانی (پیش‌فرض ۴ ساعت) از پست تکراری جلوگیری می‌کنه. این روش دقیق ۱۰۰٪ نیست ولی برای اکثر موارد کار می‌کنه.
- **عکس/فیلم کانال‌های تلگرام:** دقیقاً همون فایلی که تو پست اصلی بوده، به همراه پست بازنویسی‌شده منتشر می‌شه.
- **عکس برای پست‌های سایت:** اگه خود مقاله عکس شاخص داشته باشه از همون استفاده می‌شه؛ در غیر این صورت یک عکس استوک *مرتبط از نظر موضوعی* (نه لزوماً همون صحنه‌ی خبر) از Unsplash گرفته می‌شه. **این محدودیت واقعی هوش مصنوعیه: مدل متنی نمی‌تونه واقعاً عکس دقیق همون رویداد رو "پیدا" کنه.**
- **پیام صبح‌بخیر/شب‌بخیر:** هر روز ساعت ۷:۰۰ و ۰۰:۰۰ به وقت تهران، بدون نیاز به هیچ کاری از سمت تو.

## اضافه کردن سایت خبری (RSS)

بیشتر سایت‌های خبری یک آدرس RSS دارن، معمولاً چیزی شبیه:
```
https://example.com/feed
https://example.com/rss
```
این آدرس رو به `SOURCE_WEBSITES` اضافه کن (چند تا رو با کاما جدا کن). اگه سایتی که می‌خوای RSS نداره، بگو تا بررسی کنم چطور می‌شه ازش خبر گرفت (روش‌های دیگه محدودتر و پیچیده‌تره).

## بقیه‌ی مراحل نصب

مراحل ساخت ربات تلگرام، گرفتن کلید Gemini، آپلود روی گیت‌هاب و دیپلوی روی Railway دقیقاً همون چیزیه که قبلاً انجام دادی — فقط کافیه محتوای `bot.py` و `requirements.txt` رو با نسخه‌ی جدید جایگزین کنی و Commit بزنی؛ Railway خودکار دوباره دیپلوی می‌کنه.

## اگه چیزی درست کار نکرد

لاگ‌های Railway (Deployments → آخرین Deploy → Logs) همیشه دقیق می‌گن مشکل کجاست. اگه خطایی دیدی، اسکرین‌شاتش رو بفرست.
