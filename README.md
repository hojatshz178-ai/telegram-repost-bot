# ربات ترجمه و بازنشر خودکار پست‌های تلگرام

این ربات پست‌های جدید از کانال‌های انگلیسی مشخص‌شده رو می‌خونه، با DeepSeek به سبک گزارش نظامی کوتاه بازنویسی می‌کنه، امضای ثابت کانالت رو اضافه می‌کنه و خودکار توی کانال خودت پست می‌کنه.

## مرحله ۱: ساخت ربات تلگرام
۱. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده
۲. دستور `/newbot` رو بزن و اسم و یوزرنیم دلخواه بده
۳. یک **توکن** بهت می‌ده، مثل: `123456:ABC-DEF...` — اینو نگه‌دار (`BOT_TOKEN`)
۴. ربات رو به کانال خودت **ادمین** کن (با دسترسی ارسال پیام)

## مرحله ۲: گرفتن Chat ID کانال خودت
- اگه کانالت پابلیک با یوزرنیمه، می‌تونی مستقیم از `@youchannelusername` استفاده کنی (این می‌شه `TARGET_CHAT_ID`)
- اگه پرایوته، باید عددی شکل `-100xxxxxxxxxx` رو پیدا کنی (می‌تونم راهنماییت کنم اگه لازم شد)

## مرحله ۳: گرفتن DeepSeek API Key
۱. از مرورگر گوشی به [platform.deepseek.com](https://platform.deepseek.com) برو
۲. ثبت‌نام کن (با ایمیل)
۳. از بخش **API Keys** یک کلید جدید بساز — این می‌شه `DEEPSEEK_API_KEY`
۴. حساب معمولاً با یه مقدار اعتبار اولیه‌ی رایگان شروع می‌شه؛ برای حجم کم پست کاملاً کافیه (قیمتش هم به‌شدت پایینه نسبت به بقیه)

## مرحله ۴: آپلود کد روی گیت‌هاب (از گوشی)
۱. اگه اکانت گیت‌هاب نداری، توی [github.com](https://github.com) از مرورگر گوشی ثبت‌نام کن
۲. یک ریپازیتوری جدید بساز (مثلاً `telegram-repost-bot`)
۳. فایل‌های `bot.py`، `requirements.txt` و `Procfile` رو از طریق گزینه‌ی «Add file → Upload files» توی گیت‌هاب آپلود کن (این کار کاملاً از مرورگر گوشی قابل انجامه)

## مرحله ۵: دیپلوی روی Railway
۱. به [railway.app](https://railway.app) برو و با اکانت گیت‌هابت وارد شو
۲. **New Project → Deploy from GitHub repo** رو بزن و ریپازیتوری‌ات رو انتخاب کن
۳. Railway خودش `requirements.txt` و `Procfile` رو تشخیص می‌ده و اجرا می‌کنه
۴. برو به تب **Variables** پروژه و این متغیرها رو اضافه کن:

| نام متغیر | مقدار |
|---|---|
| `SOURCE_CHANNELS` | لیست یوزرنیم کانال‌های انگلیسی با کاما، بدون @ (مثل `channel1,channel2`) |
| `TARGET_CHAT_ID` | آیدی یا یوزرنیم کانال خودت (مثل `@mychannel`) |
| `BOT_TOKEN` | توکنی که از BotFather گرفتی |
| `DEEPSEEK_API_KEY` | کلیدی که از DeepSeek گرفتی |
| `POLL_INTERVAL_SECONDS` | (اختیاری) هر چند ثانیه چک کنه، پیش‌فرض ۳۰۰ (۵ دقیقه) |

امضای پایین هر پست (هشتگ و آیدی کانال) دیگه از Environment Variable خونده نمی‌شه؛ داخل خود `bot.py` به‌صورت ثابت تنظیم شده:
```
#raptor
————————
@khaatshekaan
```

۵. بعد از ذخیره‌ی متغیرها، Railway خودکار ربات رو دوباره اجرا می‌کنه. توی تب **Deployments → Logs** می‌تونی ببینی داره کار می‌کنه یا نه.

## نکات مهم
- ربات فقط از کانال‌های **پابلیک** می‌تونه بخونه (چون از صفحه‌ی پیش‌نمایش عمومی `t.me/s/...` استفاده می‌کنه، نه از یوزربات با شماره تلفن — به همین خاطر نیازی به لاگین با کد تایید نیست)
- اولین باری که هر کانال منبع اضافه می‌شه، ربات فقط پست‌های *بعدی* رو پردازش می‌کنه (آرشیو قدیمی رو یکجا پست نمی‌کنه)
- سبک نوشتار الان «گزارش نظامی/اطلاعاتی کوتاه» تنظیم شده: حداکثر ۴ تا ۶ خط، لحن مستقیم و دقیق، فقط ۱ تا ۲ ایموجی مرتبط. اگه خواستی این سبک تغییر کنه، فقط بگو تا متغیر `REWRITE_PROMPT` رو ویرایش کنم
- روی پلن رایگان Railway ماهی چند ساعت اجرای رایگان می‌دن؛ برای اجرای ۲۴/۷ ممکنه نیاز به ارتقا به پلن پولی (چند دلار در ماه) داشته باشی
- DeepSeek از ایران معمولاً بدون نیاز به VPN در دسترسه، ولی چون کد روی سرور Railway اجرا می‌شه، حتی اگه محدود هم بود مشکلی برای اجرای ربات پیش نمی‌آد

## اگه خواستی چیزی رو تغییر بدی
اگه بعداً خواستی لحن ترجمه عوض بشه، کانال جدید اضافه/کم بشه، یا فرمت پست تغییر کنه، کافیه بگی چی می‌خوای — می‌تونم کد رو برات ویرایش کنم.
