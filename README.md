# Raptor Military News Bot — public Telegram source mode

این نسخه برای اجرا روی Railway طراحی شده و **به Telegram API ID / API HASH / Telethon Session نیاز ندارد**.

## معماری

- خواندن کانال‌های عمومی منبع از نمای عمومی Telegram (`t.me/s/<channel>`)
- دریافت متن و رسانه‌هایی که نمای وب عمومی Telegram در اختیار می‌گذارد
- تشخیص خبر نظامی/غیرمرتبط با Gemini
- گروه‌بندی چند گزارش درباره یک واقعه
- بازنویسی فارسی طبق قوانین تحریریه
- صف اولویت‌دار با فاصله ۶۰ دقیقه و کاهش تدریجی تا حداقل ۳۰ دقیقه در زمان شلوغی
- ساعات سکوت ۰۰:۰۰ تا ۰۸:۰۰ به وقت تهران
- خبرهای فوری با اولویت بالاتر
- حذف خبرهای کم‌اهمیت باقی‌مانده در نیمه‌شب
- پیام صبح بخیر ۰۸:۰۰ و شب بخیر ۰۰:۰۰ با تصویر
- ارسال به کانال هدف از طریق Telegram Bot API
- استفاده از Wikimedia Commons به‌عنوان تصویر جایگزین وقتی رسانه منبع در دسترس نیست
- مدیریت ۲۹ کلید Gemini با چرخش، cooldown، retry، backoff و محدودیت هم‌زمانی برای کاهش خطاهای 429/503

## نکته مهم درباره رسانه

این نسخه عمداً بدون حساب کاربری Telegram کار می‌کند. بنابراین رسانه‌ای که در صفحه عمومی Telegram قابل دسترسی نباشد، مخصوصاً بعضی فایل‌های ویدئویی اصلی، ممکن است از طریق نمای وب قابل دانلود نباشد. در چنین حالتی ربات از تصویر جایگزین استفاده می‌کند؛ هیچ رسانه‌ای را از خودش به‌عنوان رسانه منبع جعل نمی‌کند.

## GitHub

در GitHub این فایل‌ها/پوشه‌ها را قرار بده:

- `app/`
- `tools/` (در این نسخه ابزار Telethon حذف شده و پوشه می‌تواند خالی باشد)
- `Dockerfile`
- `railway.json`
- `requirements.txt`
- `.env.example`
- `.gitignore`
- `README.md`
- `data/.gitkeep`
- `media/.gitkeep`

**فایل `.env` خصوصی را در GitHub نگذار.** متغیرها را در Railway Variables قرار بده.

## Railway Variables ضروری

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_TARGET_CHANNEL`
- `TELEGRAM_SOURCE_CHANNELS`
- `GEMINI_API_KEY_1` تا `GEMINI_API_KEY_29`

بقیه متغیرها مقدار پیش‌فرض دارند و در صورت نیاز قابل تغییرند.

## دسترسی ربات به کانال هدف

ربات باید در کانال هدف دسترسی لازم برای ارسال پست داشته باشد.

## کانال‌های منبع

کانال‌های منبع باید عمومی باشند تا `t.me/s/...` بتواند محتوای آن‌ها را نشان دهد. این نسخه برای کانال خصوصی یا محتوایی که Telegram در نمای عمومی وب نشان نمی‌دهد طراحی نشده است.

## اجرای محلی

```bash
pip install -r requirements.txt
python -m app.main
```

برای Railway، Dockerfile اجرای سرویس را انجام می‌دهد.
